# DMV Restorations Inc. — Homepage

A premium homepage redesign concept for **DMV Restorations Inc.**, a Class A General Contractor serving Washington DC, Maryland, and Virginia across restoration, remodeling, and commercial & residential property services.

**Live:** https://mjacobg2002-ant.github.io/dmv-restorations/

## About this build
- Static site — no build step. Plain HTML, CSS, and vanilla JS.
- All project photography is the company's **real work**, sourced from the existing DMV Restorations website and re-organized into a maintainable local image library under `assets/img/`.
- The real DMV Restorations logo is used as-is.
- Content reflects only verified positioning from the current site (Class A GC; 20+ years; licensed, bonded & insured; DC·MD·VA; Chamber of Commerce verified; approved vendor on RealPage, NetVendor & VendorCafe; 24/7 emergency restoration). No testimonials, ratings, awards, or other claims have been invented.

## Structure
```
index.html            Homepage
css/styles.css        Design system + all sections
js/main.js            Mobile menu, scroll reveals, portfolio filter, form
assets/img/           Real project photography (hero, restoration, kitchens,
                      bathrooms, flooring, commercial, portfolio) + logo
```
